# Power BI Sales Dashboard

This project presents an interactive sales dashboard created using Power BI.

## Tools Used
- Power BI
- Data Visualization

## Dashboard Features
- Total Sales KPI
- Total Orders KPI
- Total Quantity KPI
- Average Price KPI
- Sales by Product
- Sales by Category
- Sales Trend Analysis
- Sales by City
- Top Products Analysis
- Interactive Slicers

## Business Insights
- Identified top-selling products.
- Analyzed category-wise sales performance.
- Found high-performing cities and sales trends.
